# 欢迎来到 Note-Up

这是一个演示站点。所有内容都来自本地 Obsidian Vault，源文件是唯一真相，数据库只是可以随时重建的索引。

## 从这里开始

- 了解 [[Obsidian方言指南]]，看看常见语法如何转换。
- 阅读 [[索引器设计|索引器是怎么工作的]]。
- 查看 [[子目录/项目计划]]。

## 标签

行内标签也会被索引，例如 #实战 #阅读。多级标签也可以：#项目/note-up。

> [!note] 发布开关
> 只有 frontmatter 中显式写了 `publish: true` 的笔记才会发布。缺失或为 `false` 时一律不发布，这是 fail-safe 策略。

> [!tip]- 小提示
> 点击这个折叠 Callout 可以展开内容。

## 这里不该出现

下面的 Dataview 查询会在索引时被剥离，避免把原始查询暴露到网页：

```dataview
TABLE file.mtime AS "更新"
FROM "笔记"
WHERE publish = true
```
