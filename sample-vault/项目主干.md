# Obsidian笔记发布系统
## 1 项目定位
### 目标
- 本地vault自动发布到Web
- 不改造源笔记
- 支持评论交互
### 角色
- 管理员ADMIN
- 游客GUEST
- 未登录访客
### 规模假设
- 当前100篇
- 按千篇以内规划
- 不做过度扩展
## 2 技术栈
### 后端
- Spring Boot 3
- Java 25
- Spring Security + JWT
- MyBatis-Plus
- flexmark-java
- snakeyaml
### 前端
- Vue 3 + TypeScript
- Vite
- Pinia
- Vue Router
- Element Plus
- highlight.js / mermaid.js / KaTeX
### 存储
- MySQL 8.0
- InnoDB ngram FULLTEXT
- 文件系统存vault与附件
### 工具
- rsync
- cron
- Nginx
- Maven / Vite
## 3 系统架构
### 同步层
- 本地vault

- 排除.obsidian与.trash

- rsync后SSH hook

### 索引层
- VaultIndexer全量扫描

### 服务层
- 公开API
- 认证API
- 评论API
- 管理API
### 展示层
- 游客端页面
- 管理端页面
