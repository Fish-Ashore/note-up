# 字符串形式的发布开关

这篇笔记的 frontmatter 使用了带引号的字符串：

```yaml
publish: "true"
```

索引器会把 `true`、`yes`、`1` 都视为启用发布。只有缺失、`false`、`no` 或无法识别的值才会被视为不发布。

> [!note] fail-safe
> 缺失 `publish` 一律不发布。这样可以避免因为忘记添加字段而泄露私密笔记。

对比一下：`publish: false` 的 [[未发布]] 不会出现在公开站点，而 [[欢迎]] 会正常展示。
